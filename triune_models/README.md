# Triune Native Model Zoo (`triune-models`)

Contains model weights, architecture specifications, and benchmarks for native Triune models.

## Native Model Presets

- **`triune-base`**: 2.5B MoE with GLA Attention, Limbic/Reflex exit heads, CentroidSteer optimizer.
- **`triune-small`**: 750M Dense GLA model for lightweight laptop inference.
- **`triune-moe`**: 5B fine-grained MoE model for high-throughput reasoning tasks.
